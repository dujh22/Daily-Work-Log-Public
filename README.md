# Daily-Work-Log-Public

本仓库为个人公开工作日志存储库，定期同步记录工作内容、任务进展与成果沉淀。既用于自我复盘总结、梳理工作脉络，也方便他人直观了解项目推进情况与工作动态，实现透明化的工作分享与交流。

## 目录结构

```
.
├── Years/       # 年度工作日志
│   ├── 2025.md          # 2025 年度记录
│   ├── 2026.md          # 2026 年度记录
│   └── Days/            # 每日详细日志（按日期归档）
├── NoteBooks/   # 学习与研究笔记
│   └── LLM/             # 大模型相关笔记
│       ├── 框架/        # RL / RLHF / SFT / 部署
│       ├── 模型/        # Deepseek / GPT / Qwen 等
│       └── 研究/        # 训练 / 数据 / 评估
├── Works/       # 工作事务
│   └── Social_Works/    # 社会工作（组织生活等）
├── Rewards/     # 荣誉与奖项记录
└── Others/      # 其他记录
    └── Sports/          # 运动日志（网球、游泳等）
```

## 使用说明

- **年度日志**：`Years/` 下按年份汇总，每日详情见 `Years/Days/`。
- **学习笔记**：`NoteBooks/` 沉淀大模型方向的框架、模型与研究笔记。
- **荣誉记录**：`Rewards/` 按年份及奖项类别归档。

仓库内容持续更新中，欢迎交流。
