# 工作日志

每日日志按年份归档,是本仓库的事实源;各年份 `README.md` 为人工整理的年度摘要。

## 使用方式

- 新日志:复制 [../templates/daily.md](../templates/daily.md) 到 `logs/<year>/YYYY-MM-DD.md` 起稿。
- 日志正文结构见模板:关键注意点 → 计划 → 主要工作(分时段)→ 每日回顾。
