# 网球

## 学习路径

1. 热身：跑3圈，颠球
2. 注意事项
   1. 身体始终要压低
   2. 是在使用腰部的旋转带动手臂
   3. 最终要目视前方
   4. 脚步：向前、向后、向上（近网）、向外（远网）
3. 正手接球：近距离静态、近距离动态（双脚始终小碎步）、隔网远距离动态
4. 反手接球：近距离静态、近距离动态、隔网远距离动态
