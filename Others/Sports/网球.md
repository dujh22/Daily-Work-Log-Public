# 网球

## 学习路径

1. 热身：跑3圈，颠球
2. 注意事项
   1. 身体始终要压低
   2. 是在使用腰部的旋转带动手臂
   3. 球触拍是在身前，触网后手臂即可放松
   4. 最终要目视前方
   5. 一旦对方发球，就要做好引拍
   6. 在球未落的时候就要判断会落在哪里
      1. 如果是后1/2场就该退了
      2. 脚步：向前 / 上（近网）、向后（退）、侧身（背指向的方向）、向外（胸指向的方向）
3. 正手接球：近距离静态、近距离动态（双脚始终小碎步）、隔网远距离动态
4. 反手接球：近距离静态、近距离动态、隔网远距离动态
5. 交替接球：自由判断球，然后决定是正手还是反手
