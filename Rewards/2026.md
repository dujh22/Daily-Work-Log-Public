6. 基础模型北京市重点实验室：Self-improving Al systems aim to reduce reliance on human engineering by learning tomprove their own learning and problem-solving processes. Existing approaches to self-mprovement rely on fixed, handcrafted meta-level mechanisms, fundamentally limiting howfast such systems can improve. The Darwin Godel Machine (DGM) demonstrates open-endedself-improvement in coding by repeatedly generating and evaluating self-modified variantsBecause both evaluation and self-modification are coding tasks, gains in coding ability cantranslate into gains in self-improvement ability. However, this alignment does not generallyhold beyond coding domains. We introduce Itextbf{hyperagents), self-referential agents thatintegrate a task agent (which solves the target task) and a meta agent (which modifies itselfand the task agent) into a single editable program. Crucially, the meta-level modificationorocedure is itself editable, enabling metacognitive self-modification, improving not only thetask-solving behavior, but also the mechanism that generates future improvements. Weinstantiate this framework by extending DGM to create DGM-Hyperagents (DGM-H),eliminating the assumption of domain-specific alignment between task performance and self-modification skill to potentially support self-accelerating progress on any computable task.Across diverse domains, the DGM-H improves performance over time and outperformsbaselines without self-improvement or open-ended exploration, as well as prior self-improvingsystems. Furthermore, the DGM-H improves the process by which it generates new agentse.g., persistent memory, performance tracking), and these meta-level improvements transferacross domains and accumulate across runs. DGM-Hyperagents offer a glimpse of open-ended Al systems that do not merely search for better solutions, but continually improve theirsearch for how to improve.
7. Recent AI Scientist and self-evolving agent systems have shown promising resultson narrow tasks such as circle packing and nanoGPT speedruns. However, itremains unclear whether today's LLMs can make generalizable, reusable, andscalable methodological discoveries for machine learning research.In this talk, I will introduce MLS-Bench for Machine Learning Science, a benchmarkfor evaluating whether LLMs can invent new ML methods. MLS-Bench includes 140tasks across 12 ML areas, where each task asks a model to improve a clearlyspecified ML component within a fixed editable region of a given codebase, andevaluates the result against strong human baselines across multiple settingsOur results show that current frontier LLMs still struggle to outperform stronghuman-designed methods. Additional knowledge, baseline implementations, websearch, or more test-time compute yield only limited gains, while giving agentsmore freedom to design experiments can even hurt performance. These findingssuggest that the bottleneck is not only knowledge or idea generation, but researchjudgment: deciding what to test, how to validate it, and how to turn feedback intoscalable evidence.
   I will conclude by discussing what these results imply for building Al systems thatcan genuinely accelerate ML research, and why the next challenge may bescalable discovery under unscalable verification.
